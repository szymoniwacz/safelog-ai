## Why this stack

SafeLog AI is a solo, after-hours web MVP (three weeks) with email/password auth, encrypted diagnostic storage, in-memory redaction, and AI-generated hypothesis reports — no background jobs or payment processing in v1. Shape notes targeted Ruby on Rails; you corrected the UI to React in the same repository while keeping Rails as the backend, so the standard `(web-app, ruby)` default applies: `rails` with **SQLite for MVP** (simpler, cheaper Fly/course deploy; Active Record Encryption still applies). PostgreSQL is a future option if scale requires it. Bootstrap used `--database postgresql`; switching app config to SQLite is a planned implementation step. Verified bootstrapper confidence and convention-heavy structure agents handle well. React is not generated by the Rails starter CLI; plan a same-repo Vite/React frontend (e.g. via vite_rails) after scaffold. Fly.io deployment and GitHub Actions with auto-deploy on merge match the chosen operational defaults. Auth and AI feature flags are set; realtime, payments, and async workers stay out of scope per the PRD.
