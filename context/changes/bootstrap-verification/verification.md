Shape notes targeted Ruby on Rails; you corrected the UI to React in the same repository while keeping Rails as the backend, so the standard `(web-app, ruby)` default applies: `rails` with **SQLite for MVP** (simpler, cheaper Fly/course deploy; Active Record Encryption still applies). Verified bootstrapper confidence and convention-heavy structure agents handle well. React is not generated by the Rails starter CLI; plan a same-repo Vite/React frontend (e.g. via vite_rails) after scaffold. Fly.io deployment and GitHub Actions with auto-deploy on merge match the chosen operational defaults.
